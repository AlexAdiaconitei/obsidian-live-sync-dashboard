The LiveSync Dashboard manages the CouchDB server behind
[Obsidian LiveSync](https://github.com/vrtmrz/obsidian-livesync). It runs next to CouchDB, inside
your Tailscale tailnet, and serves two portals:

- **Administration**, for the people listed in `PANEL_ADMINS`. Create people and vaults, adopt
  databases that already exist, set storage quotas, watch instance backups and read the activity
  log.
- **Owner portal**, for everyone else. Each person sees their own vaults, sets their sync
  password, generates encrypted setup URIs for new devices and backs their vaults up to their own
  Google Drive.

Obsidian clients sync through a third endpoint, the quota gateway, which enforces storage limits
before writes reach CouchDB.
